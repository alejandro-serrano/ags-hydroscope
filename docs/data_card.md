# Data card: Aguascalientes land-use patches

## Source

Sentinel-2 L1C (`COPERNICUS/S2_HARMONIZED`, 13 bands, digital numbers = reflectance x 10000)
from Google Earth Engine. One median composite of April 2024 (peak of the dry season), clouds
masked with QA60 bits 10 and 11, all bands resampled to 10 m, clipped to the state of
Aguascalientes, EPSG:32613. Export code: `src/hydroscope/geo/gee_export.py`; raster check:
`docs/data_ags_check.md`.

## Processing

- 640 m grid anchored on the absolute 640 m lattice, one `cell_id` per cell (`src/hydroscope/geo/grid.py`).
- One patch per cell: 13 x 64 x 64, `uint16`, TorchGeo EuroSAT band order (B01 ... B12, B8A last)
  (`src/hydroscope/geo/tiling.py`). Only cells with at least 80 % inside the state and 60 % valid
  pixels get a patch.
- An RGB PNG preview (B04, B03, B02, 2-98 % stretch) is used for labeling.
- Exact formats: `docs/contracts.md`.

## Labeling

Labels follow `labeling/GUIDE.md` (Spanish: `labeling/GUIDE.es.md`), using the 10 EuroSAT classes
on the April 2024 preview:

- A cell gets a class only if at least 70 % of it is that class (Highway and River are labeled by
  the dominant element, as in EuroSAT).
- Tie-breakers for semi-arid confusions: parcel pattern is AnnualCrop; trees or vines in rows are
  PermanentCrop; managed grazing grass is Pasture, other grass and xeric scrub is
  HerbaceousVegetation; continuous canopy over 70 % is Forest.
- Cover without a EuroSAT class (greenhouses, quarries, bare rock or soil, and any doubtful cell)
  is marked `skip`. Skipped cells are never used for training or evaluation.

There is a single annotator, `A1`. With one annotator there is no inter-annotator agreement, so
no Cohen's kappa is reported and label noise is unmeasured.

Revision note: the first 547 cells were labeled with guide v1 and all of them were re-labeled with
the current guide on 2026-10-09; 309 changed class, mostly Pasture to HerbaceousVegetation (69)
and PermanentCrop to AnnualCrop (59). `data/ags/labels.csv` contains only the current version.

recorded in `docs/protocol.md`. Counts below are generated by the script.

## Limitations

- Single annotator and no agreement measure; labels reflect one interpretation of the guide.
- Single date (April 2024, dry season): rainfed fields look bare, so the shift to EuroSAT also
  mixes season and region. Results do not cover the rainy season or other years.
- Spatial autocorrelation: neighbouring blocks are similar, so the block split reduces but does
  not remove optimistic bias.
- Class imbalance: rare classes (for example River, Highway, SeaLake) have few patches and their
  F1 is noisy.
- Labels come from the preview and a recent basemap, not from field data.
- The half/half block split balances classes only approximately.
