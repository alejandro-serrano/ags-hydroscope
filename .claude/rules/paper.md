# Paper and slides rules

- English only, IEEE conference style (IEEEtran), past tense for what was done.
- Numbers come from `paper/tables/*.tex` or `paper/figures/*` generated by `/results-tables`.
  Never type a metric by hand; if it is missing, write `\todo{source missing}`.
- Cite only keys that exist in `paper/references.bib`.
- Figures: vector PDF, readable at column width (≥ 8 pt text), colour-blind-safe palette.
- State limitations: one seed, ~200-patch test set, single month (April 2024), 64-px patches.
